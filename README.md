# UPI Transactions & Financial Dashboard (Excel)

An interactive Excel dashboard built to analyze and visualize UPI (Unified Payments Interface) transaction data, tracking spending patterns, payment methods, and monthly financial flows.

## 🚀 Features
- *Transaction Overview:* High-level summary of total spending, received amounts, and net balance.
- *Category-wise Breakdown:* Visualizing expenses across categories (e.g., Groceries, Utilities, Entertainment, Dining).
- *Trend Analysis:* Monthly and daily transaction trends using dynamic charts and pivot tables.
- *Payment App Tracking:* Insights into usage distribution across popular UPI apps.

## 🛠️ Tools & Techniques Used
- *Microsoft Excel:* Advanced Formulas (XLOOKUP, SUMIFS, IF), Pivot Tables, and Pivot Charts.
- *Data Cleaning & Modeling:* Structured data formatting, validation, and date-wise aggregation.
